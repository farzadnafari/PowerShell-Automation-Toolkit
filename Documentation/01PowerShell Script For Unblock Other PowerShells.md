
> [!INFO] تحلیل اسکریپت پاورشل برای رفع انسداد و اجرای فایل
> این اسکریپت مسیر فایل پاورشل موردنظر را در متغیر $ScriptPath با نام ***A***.ps1 ذخیره می‌کند.
> با استفاده از Test-Path بررسی می‌کند که فایل مشخص‌شده وجود داشته باشد و از نوع فایل معمولی باشد.
> در صورت پیدا نشدن فایل، پیام خطا با رنگ قرمز و مسیر فایل با رنگ زرد نمایش داده می‌شود.
> در صورت نبود فایل، دستور Pause اجرا شده و اسکریپت با کد خروج ۱ خاتمه می‌یابد.
> با استفاده از Unblock-File تلاش می‌کند محدودیت انسداد فایل دانلودشده را حذف کند.
> پارامتر SilentlyContinue باعث می‌شود خطاهای مربوط به دستور Unblock-File نمایش داده نشوند.
> فایل اصلی با اجرای PowerShell.exe و پارامتر File اجرا می‌شود.
> پارامتر NoProfile مانع بارگذاری پروفایل کاربر در فرایند جدید پاورشل می‌شود.
> پارامتر ExecutionPolicy Bypass محدودیت‌های سیاست اجرای پاورشل را برای فرایند جدید دور می‌زند و پس از پایان اجرا، سه بار پیام درخواست فشردن Enter نمایش داده می‌شود.


> [!INFO] PowerShell Script Unblock and Execution Analysis
> The script defines the target PowerShell file path in the $ScriptPath variable as ***A***.ps1.
> Test-Path checks whether the specified path exists and refers to a regular file.
> If the file is missing, an error message is displayed in red and the file path in yellow.
> When the file is missing, Pause is executed and the script terminates with exit code 1.
> Unblock-File attempts to remove the downloaded-file blocking restriction from the specified script.
> The SilentlyContinue error action suppresses error messages generated by Unblock-File.
> PowerShell.exe launches a separate PowerShell process to execute the target script using the File parameter.
> The NoProfile parameter prevents the new PowerShell process from loading the user's profile.
> The ExecutionPolicy Bypass parameter bypasses execution policy restrictions for the new process, and three consecutive Read-Host commands prompt the user to press Enter after execution.


```
# =====================================================================
# POWERSHELL SCRIPT UNBLOCK / RUNNER
# =====================================================================

$ScriptPath = "***A***.ps1"

# Check file
if (-not (Test-Path -LiteralPath $ScriptPath -PathType Leaf)) {
    Write-Host "ERROR: Script file not found:" -ForegroundColor Red
    Write-Host $ScriptPath -ForegroundColor Yellow
    Pause
    exit 1
}

# Unblock downloaded script
Unblock-File -LiteralPath $ScriptPath -ErrorAction SilentlyContinue

# Run with ExecutionPolicy Bypass
PowerShell.exe `
    -NoProfile `
    -ExecutionPolicy Bypass `
    -File $ScriptPath

Read-Host "Press ENTER to exit"

Read-Host "Press ENTER to exit"

Read-Host "Press ENTER to exit"
```
